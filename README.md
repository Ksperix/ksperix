# ksperix.dev — Personal Portfolio & Infrastructure Ecosystem

Oficjalne repozytorium portfolio wizytówkowego i serwisu prezentującego ekosystemy operacyjno-technologiczne, automatyzacje oraz dedykowane rozwiązania webowe tworzone przez **ksperix.dev**.

 Live Demo: [ksperixdev.vercel.app](https://ksperixdev.vercel.app/)

---

##  O Projekcie

Aplikacja to nowoczesne, wysoko wydajne portfolio stworzone przy użyciu **Next.js** i **Tailwind CSS**. Nie prezentuje jedynie klasycznego "zbioru linków", lecz kompleksowe podejście do projektowania infrastruktury operacyjnej, narzędzi małej/średniej automatyzacji oraz nowoczesnego brandingu.

### Kluczowe Sekcje Strony:
- **Hero & Mission:** Prezentacja misji – budowanie infrastruktury operacyjnej i skalowanie procesów zespołowych.
- **O mnie & Tech Stack:** Profil doświadczenia (zarządzanie społecznością BrainlyHQ, ekosystemy Adult UGC / VANTRX, automatyzacje Slack/Discord).
- **Kompetencje:** Architektura serwerów, zarządzenie zespołami, nowoczesne aplikacje webowe oraz branding/marketing.
- **Wybrane Projekty:** Przewijana linia kart w formacie 16:9 (BrainlyHQ Ecosystem, VANTRX Platform, Les Moutons Bags, Partnership Network, Notifications System, Gamez & Automation).
- **Czym jest Skuteczny Ekosystem:** Prezentacja zasad działania centralizacji komunikacji, botów automatyzujących i analityki.
- **Dedykowany Moduł VANTRX:** Prezentacja infrastruktury wspierającej branżę Adult UGC.
- **Kontakt & Footer:** Szybki kontakt oraz odnośniki do profilu GitHub i Discorda (`ksperix.dev`).

## 🛠️ Uruchomienie Lokalnie

Aby uruchomić projekt na lokalnym środowisku programistycznym:

1. **Sklonuj repozytorium:**
   ```bash
   git clone https://github.com/ksperix/ksperixdev.git
   cd ksperixdev
   ```

2. **Zainstaluj zależności:**
   ```bash
   npm install
   # lub
   pnpm install
   # lub
   yarn install
   ```

3. **Uruchom serwer deweloperski:**
   ```bash
   npm run dev
   ```

4. Otwórz [http://localhost:3000](http://localhost:3000) w przeglądarce.
